## Guidelines

- Everything here is frozen. Do not fix, update, run, or modernize archived files; they record how a retired setup worked.
- Add a retirement as one topic folder that keeps each file's original repository path, and add the topic to the README table.
- Live code belongs in `Zihad550/dotfiles` (portable configuration, headless installers, setup entry point) or `Zihad550/arch-desktop` (Arch desktop); retire from there to here. See arch-desktop ADR 0041.
